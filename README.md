# avpr-feed

خوراک مطالب سایت [avpr.ir](https://avpr.ir) (مرجع تخصصی روابط عمومی هوانوردی).

- `feed.json`: فهرست مطالب آماده‌ی انتشار، جدیدترین در ابتدا.
- `images/`: عکس شاخص هر مطلب (از Wikimedia Commons با مجوز آزاد؛ نام عکاس و مجوز زیر هر مطلب درج می‌شود).
- `tools/add_item.py`: افزودن یک مطلب به خوراک.

افزونه‌ی «AVPR Feed Importer» روی سایت هر ۱۵ دقیقه این مخزن را می‌خواند و مطالب تازه را منتشر می‌کند
(پیشخوان وردپرس ← ابزارها ← AVPR Feed).

## تیتر کوتاه اسلایدر

هر مطلب باید `short_title` داشته باشد: تیتری حداکثر ۸ کلمه‌ای که در اسلایدر صفحه اصلی نمایش داده می‌شود (مثلاً «لغو دستور توقف پروازها در آمریکا»). تیتر بلند هرگز بریده یا با سه‌نقطه کوتاه نشود؛ تیتر کوتاه را جداگانه و کامل بنویسید. افزونه آن را در فیلد `avpr_short_title` ذخیره می‌کند.
